# Connexion du robot Xiaomi

1. Relever modèle, firmware, IP fixe et région Mi Home, sans demander de jeton.
2. Déclarer seulement le pilote et son adresse locale ; préparer le relais RAM décrit
   dans l'intégration caméra Xiaomi, sans publier ses ports.
3. Dans **Paramètres**, le propriétaire saisit son compte Xiaomi, puis lui-même le
   captcha ou le code de vérification. Privilégier HTTPS ; toute exception HTTP sur
   le LAN doit être acceptée en connaissance du transport non chiffré.
4. Vérifier modèle, firmware, batterie et état en lecture seule. La connexion ne doit
   déplacer ni réveiller physiquement le robot.
5. Charger la carte dans **Aspirateur**. Comparer base, murs et orientation au plan
   réel. Dessiner la cuisine ; confirmer sans lancer le nettoyage. Une capture seule
   ne suffit pas à convertir les coordonnées.
6. Activer les déplacements seulement après cette recette. Avec un humain présent,
   essayer explicitement la cuisine ; ne pas transformer ce test en nettoyage global.
7. Après changement de carte/base/robot, reconfirmer la zone. Tester refus de carte
   périmée, coupure réseau et absence de rejeu. Ne pas déplacer la base pour un test.

Aucun changement de région, firmware, appairage ou compte Mi Home automatique.
